# Curriculum Audit and Workflow Improvement Assessment

This repository contains my submissions for Task 1 and Task 2.

## Task 1 — SIS Issue-Reporting Workflow

Investigates the student process for reporting a problem in the ICFAI Student Information System (SIS) and proposes a structured ticket-based workflow.

**Contents**
- `task1/workflow_scope.md` — Scope, current-state workflow, and evidence log.
- `task1/improved_workflow.md` — Proposed workflow, statuses, ownership, routing, and fallback procedures.
- `task1/synthetic_test_cases.md` — Five synthetic test cases and expected outcomes.
- `task1/scale_and_time_saving.md` — Illustrative net time-saving calculation and sensitivity analysis.
- `task1/final_report.md` — Consolidated report.

The proposed workflow has not been implemented or tested in the live SIS. The time-saving figures are illustrative assumptions, not measured institutional results.
